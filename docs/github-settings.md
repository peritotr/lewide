# GitHub repository settings

Paste these into the repository page once it exists (github.com/peritotr/lewide).

## About (gear icon next to "About")

**Description** (shown in search results, keep under 160 characters):

> Free, open-source database client and SQL editor for PostgreSQL, MySQL, SQLite, SQL Server, ClickHouse, DuckDB, Redis, MongoDB, Qdrant and Neo4j, with an AI assistant.

**Website:** leave empty until there is a site, or use the releases page.

**Topics** (GitHub allows 20):

```
database-client sql-editor database-gui database-management postgresql mysql sqlite sql-server clickhouse duckdb redis mongodb qdrant neo4j tauri rust react ai-assistant dbeaver-alternative navicat-alternative
```

Untick Packages and Deployments if they stay unused; keep Releases.

## Social preview

Settings → General → Social preview → Edit → upload `docs/assets/social-preview.png`
(1280×640). This is the image shown when the link is shared on X, LinkedIn, Slack and others.

## Other settings that help people find and trust the project

- Settings → General → Features: turn on **Discussions** (questions stay out of issues).
- Settings → Code security: turn on **Dependabot alerts** and **Private vulnerability reporting**.
- Pin the repository on the profile page.
- With the first release, attach the installers and write release notes; releases appear in search and in the sidebar.
